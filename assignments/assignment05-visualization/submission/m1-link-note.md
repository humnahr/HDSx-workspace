# M1 Link Note

The visual audit showed why it's important to include all relevant data and make sure the graph matches what's being measured. For M1, the planned NHANES visualization will compare PHQ-9 depression scores across income groups using the poverty-income ratio (`IND_FMPIR`), with age considered as an additional variable. Missing values and group sizes will need to be accounted for, and the caption should make it clear that any differences are descriptive rather than evidence that income causes depression.
