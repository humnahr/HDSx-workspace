# Provenance and Stewardship Note

The dataset used for this assignment is the prepared NHANES Health Equity classroom CSV (`nhanes_equity_v6.csv`). It is based on publicly available National Health and Nutrition Examination Survey (NHANES) data from the CDC, rather than data downloaded directly from NHANES for this assignment.

The file was accessed through the course GitHub workspace and used for classroom analysis. The results are descriptive and unweighted, so they only reflect the prepared dataset and should not be treated as estimates for the US population or evidence that income causes changes in BMI.

Although the original NHANES data is publicly available, individual-level records should still be handled carefully. Row-level data should not be uploaded to external AI tools, and results should be reported without making claims about identifiable individuals.
